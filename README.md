# JumpBoost

JumpBoost is a Minecraft plugin designed to enhance player movement by increasing the jump height. This plugin is perfect for servers looking to add a unique twist to player mechanics, making gameplay more dynamic and engaging. It is compatible with PaperMC and other Paper-based server implementations.

## Install

1. Download the JumpBoost plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Once the server is running with the JumpBoost plugin installed, players will automatically experience increased jump height.
2. No additional commands or configurations are required for basic functionality.
